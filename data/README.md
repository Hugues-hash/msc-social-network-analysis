# Data

`facebook_combined.txt` is the combined Facebook ego-network from the Stanford Network Analysis
Project (SNAP). It is a small edge list (about 0.85 MB), so it is included here and the notebook
runs without any extra download.

## Format

Each line is one undirected friendship as two anonymised integer user IDs:

```
0 1
0 2
...
```

4,039 nodes and 88,234 edges in total.

## Source and citation

- SNAP dataset page: https://snap.stanford.edu/data/ego-Facebook.html
- Leskovec, J. and Krevl, A. (2014) *SNAP Datasets: Stanford Large Network Dataset Collection*.
- McAuley, J. and Leskovec, J. (2012) "Learning to Discover Social Circles in Ego Networks", *NIPS*.

The data is anonymised and provided by SNAP for research use.
